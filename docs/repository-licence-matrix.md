## Dependency and asset checks

- **FFmpeg** is build-dependent. Check each binary's build configuration and the distribution obligations of enabled components before shipping a bundle. Build and codec patent questions are separate from an upstream project's MIT or Apache licence. Elevate's local existing dependency is reused for the proofs. [FFmpeg legal guidance](https://ffmpeg.org/legal.html)
- **Remotion** is a separate programmatic video runtime. Company eligibility depends on the actual organisation and terms. No licence or subscription was purchased. [Official Remotion terms](https://www.remotion.dev/license)
- **Herk graphics** pin GSAP separately, refer to CDN fonts in some templates and carry explicit AIS exclusions. Verify the selected package's terms and lockfile, localize appropriately licensed fonts and document each card asset if an overlay ever ships. No showcase media or brand marks were copied. [GSAP licence](https://gsap.com/community/standard-license/)
- **Caption fonts** already bundled by Elevate have separate OFL notices in `backend/app/render_fonts/`. Keep them with redistributed dependencies. System fonts listed by Viprasol are fallback candidates, not redistributable assets. Verify any new font and model weight at the file level before inclusion.
- **Stock and service assets** require a per-item receipt with creator/source, license, permitted publication and reuse, attribution, rights expiry when relevant, and the downloaded file hash. Provider access does not establish publication rights. Leave unidentified examples, stock, likenesses, music and clips outside the default asset library.
- **Network service code** must receive a specific review if an AGPL implementation is ever proposed. No transitive SBOM, vulnerability scan or provider contract review was completed. Findings cover inspected paths, not every dependency version or asset.

## Execution decisions

Only the reviewed MakeMyClip token matcher and Viprasol Unicode key helper were run in isolation. The former ran in a cleared Node process environment and the latter without importing its module or external dependencies. The ASS render used Elevate's existing local FFmpeg and bundled fonts. The audit reads installers and package metadata as evidence. It does not execute installers, agent prompts, browser compositions, cloud services or package hooks.

Release gates for a future adapter are reviewed source and lockfile, reproducible artifact hashes, a transitive dependency and asset licence inventory, no secret inheritance, local scratch and filesystem confinement, restricted network, allowed subprocess arguments, resource caps, technical fallback and human oversight. Optional paid seats, provider calls or uploaded footage require explicit separate approval.
