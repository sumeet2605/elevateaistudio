## Deep source findings

### MakeMyClip

- `src/transcribe/whisper.ts` wraps local whisper.cpp. `transcribeMedia` caches source word timing, `clipWords` exposes clip-relative timing and stable word indices, and `outlineSentences` is transcript navigation. Elevate already has Faster-Whisper, timestamps and a retained timeline. Reuse those inputs.
- `findRetakes` in `src/timeline/transcript.ts` finds immediate equal token sequences of two to twelve words, longest first, and rejects runs containing only one distinct token. It picks the earlier range to remove by rule. It does not score audio quality, performer delivery, filler gaps, or fuzzy corrected sentences. Its normalization retains letters and numbers but drops Devanagari marks. Repeated contiguous sentence fragments can match, but there is no separate semantic repeated-sentence classifier in this path. An immediately repeated false start can match. Isolated unfinished speech, general filler detection and independent best-take ranking were not verified in this path.
- `planWordCut` translates word indices to source boundaries, clamps to clip in/out, discards retained slivers shorter than 50 ms and checks a previously exportable composition remains exportable. The `remove_retakes` verb in `src/timeline/verbs.ts` can enforce a transcript identity. This is boundary and revision protection. Elevate's separate VAD and word guards are stronger foundations for retaining neighbouring speech.
- `buildInterchange` and `exportInterchange` in `src/timeline/interchange.ts` use rational frame timing from `interchange-layout.ts` and FCPXML 1.10 or xmeml writers. The xmeml path can emit SRT sidecars. `tests/timeline-export-all.test.ts` and the corresponding integration test exercise exporters. NLE application import and effect fidelity were not tested. Adapt a writer only when an editor export is requested and after checking notice and format fidelity.

### Herk Edit Kit

- `style-library/registry.json`, draft cards under `style-library/`, and `style-templates/{dark-graph-paper-template,left-glass-popout}/index.html` demonstrate HTML compositions, editable slots, CSS tokens, GSAP motion and layout reuse. `MOTION_PHILOSOPHY.md` and the storytelling/editing workbook are editorial patterns. Separate brand content is excluded from reuse.
- The `.agents/skills/short-form-edit/` and `cut-mistakes/scripts/find-cut-candidates.mjs` paths include edit rules, validation, candidate grouping and a Jaccard token-set comparison. Do not stage the full agent. Keep the pattern of a clean hold, restrained entrance, pause between phrases and meaningful visual accents. Caption motion and kinetic typography are HTML template/skill-level techniques. The review did not verify a standalone word-timed caption engine portable to ASS.
- `motion-showreel/scripts/{beatgrid,sfx,mix}.mjs` illustrate beat grids, accent generation and mixing. The SFX code loads a key and calls a provider. Only reuse timing ideas. Keep Elevate's sound revisions and mixing stage. Export an owned, silent transparent graphic from a licensed template if it passes the renderer gate. The kit's ElevenLabs workflow uploads audio and is unnecessary here.

### Viprasol and Hinglish

- Core scripts live in `plugins/video-studio/skills/video-studio-core/scripts/`. `transcribe.py` passes word timestamps, optional VAD, a language and initial prompt to Faster-Whisper. Model weights and inference behaviour are separate from the template suite. Hindi is supported as a language option, while reliable per-word code-switch handling and Roman Hindi conversion were not verified. The dub skill delegates translation to the host conversation or describes an optional translation model. Neither is verified as a word-aligned transliteration pipeline.
- `vs_common.py:norm` applies NFC and retains combining marks. `captions.py` uses script-aware width heuristics, line break costs, cue grouping and cue validation, and writes SRT, WebVTT, TTML and ASS. `deliver.py:font_face` probes font coverage and its fallback list includes macOS fonts. Style themes provide browser caption effects. These techniques do not establish timestamp accuracy or font shaping across all mixed-script inputs. Avoid system-font redistribution and remote font loading.
- Elevate already retains Hindi combining marks in typical text, bundles SIL OFL Noto Sans and Noto Sans Devanagari, and sets font per word in ASS. The measured gap is canonical equivalence during matching. Keep the original display text and separately canonicalize the matching key. Follow with a bilingual line-fit and reading-speed benchmark.

### Reference-video evidence

- Video Creator Skills `skills/watch-video/scripts/watch.py` extracts word-timed Faster-Whisper transcripts and scene-cut frames via FFmpeg `select`, falling back to even spacing. Its motion, reel and composition skills show creative inference from these artifacts.

Use schemas and high-level ideas where appropriate and keep all autonomous runtimes out of Elevate.

Real speakers, timing error against hand-labelled audio, accent variation and manual correction time still need measurement.
